# FILE-OPERATOR🎁

# Description🍳

This project is a menu-driven Python application that allows users to maintain a personal journal. Users can add, view, search, and delete journal entries. The application uses Object-Oriented Programming (OOP), File Handling, and Exception Handling concepts.

# 🎯 Objectives

The main objectives of this project are:

◾ To understand file handling operations in Python.

◾To perform reading and writing operations using text files.

◾To implement Object-Oriented Programming concepts.

◾To handle runtime errors gracefully using exception handling.

◾To build a menu-driven application with a user-friendly interface.


# Features✔

◾ Add new journal entries

◾ View all saved entries

◾ Search entries using keywords

◾Delete all journal records

◾Timestamp support

◾Error handling for file operations

# Technologies Used🐱‍🏍

◾ Python

◾ File Handling

◾ OOP

◾ Exception Handling

# 🎓 Conclusion

The Personal Journal Manager is a simple yet practical Python application that combines File Handling, OOP, and Exception Handling into a real-world use case.
